# 曆曆（Daylight Calendar）

曆曆把行程、天氣與自製照片貼紙放進同一張月曆，也能透過桌面小工具快速查看近期與整月安排。

## 主要功能

- 在月曆中查看裝置行事曆與自建行程
- 從照片手繪裁切透明背景貼紙
- 自由移動、縮放、旋轉貼紙並調整透明度
- 小型、中型與大型桌面小工具
- 月曆內顯示天氣預報
- 透過 iCloud 在使用同一 Apple 帳號的 iPhone、iPad 與 Mac 間同步 App 資料
- 支援繁體中文、英文、日文與深色模式
